# Capturas

Coloque aqui prints e GIFs dos dois jogos para divulgação e documentação.

Sugestão de nomes:

- `quiz-inicio.png`, `quiz-pergunta.png`, `quiz-resultado.png`
- `bug-inicio.png`, `bug-jogo.png`, `bug-ranking.png`
- `quiz-partida.gif`, `bug-partida.gif`

Para capturar no tablet: botão liga/desliga + volume para baixo. Para gravar GIF no computador, rode o jogo com `npm run servir` e use o modo de dispositivo do navegador (F12, ícone de celular) para simular o tamanho do tablet.
